## 9 novembre 2026 — issue #864

Provisioning Windows : **démarrage automatique des watchers locaux pour une machine Windows SEULE** (issue #864, suite de l'audit de parité #862), sans rapport avec le rôle CCW (`provisionner.ps1`/`ajouter_projet_ccw.ps1`, délégué depuis une seconde machine via bootstrap par issues chiffrées). Ajout de `provisioning/windows/installer_demarrage_session.ps1` — enregistre, pour un ou plusieurs projets locaux passés via `-Projets` (un `configs\<nom>.conf` doit déjà exister, jamais créé par ce script), le watcher du dépôt d'issues par fichiers (`scripts\watcher_issues_inbox.py`, sauf `-SansIssuesInbox`) et l'interface web (`new_issue.py`, équivalent fonctionnel de `lancer_new_issue.sh`, sauf `-SansInterfaceWeb`) au démarrage **dans la session** de l'utilisateur courant (tâche planifiée `-AtLogOn`, `LogonType Interactive`) — choix par défaut plutôt qu'un service Windows : un service tourne en session 0, où ni bulle de notification ni son ne peuvent sortir, et où le trousseau Windows (connexion de Claude Code/Vibe) n'est accessible que depuis la session de son propriétaire (constat réel, issue #860). Aucun mot de passe stocké en mode par défaut. Chaque process passe par le nouveau superviseur générique `provisioning/windows/surveiller_processus_session.ps1` (même rôle que `Restart=on-failure` + `SuccessExitStatus=42` de `systemd/watcher@.service`) : redémarrage automatique après un délai sur tout arrêt inattendu, pas de redémarrage sur un arrêt propre (code 0, ou 42 pour l'auto-extinction par inactivité de `watcher.py`), garde-fou « une seule instance » via fichier PID. Idempotent (mise à jour sans doublon, retrait automatique des composants retirés de `-Projets`), `-Desinstaller` (retire tout par préfixe de nom, sans redonner `-Projets`), et option secondaire `-ModeService` (service NSSM, mot de passe en saisie masquée, console administrateur requise — bulle/son explicitement documentés comme indisponibles dans ce mode). `provisionner.ps1`/`ajouter_projet_ccw.ps1` non modifiés. Nouveau guide `provisioning/windows/DEMARRAGE_SESSION_WINDOWS.md`. Code écrit et relu sous Linux, où il ne peut pas être exécuté (pas de PowerShell) — liste de vérifications manuelles dans le guide, §8.
